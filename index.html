리프랙타 — 대기 아래와 위를 함께 잽니다

Sounding the atmosphere, below and above.

GNSS 전파의 굴절에서 날씨를, 우주방사선에서 우주기상을 읽는 데이터 회사를 향해 갑니다. 이 저장소는 그 회사가 되기까지의 모든 실험과 실패와 코드를 기록합니다.

우리가 푸는 문제

기상 예보의 정확도는 관측 데이터가 결정하는데, 대기의 연직 프로파일(온도·기압·습도)은 여전히 부족합니다. 동시에 위성·항공·전력망은 우주방사선 위협에 노출되어 있는데, 이를 상시 감시하는 데이터는 더 부족합니다.

이 둘을 한 위성에서 동시에 재는 회사는 아직 없습니다 — 그것이 리프랙타의 자리입니다.

무엇을 만드는가

  • 01 부품 — 큐브샛용 방사선 검출기, 그다음 GNSS-RO 수신기. 첫 제품이자 우주 헤리티지의 시작.
  • 02 데이터 — RO 대기 프로파일 + 우주방사선 데이터 군집 서비스. 기상기관·항공·에너지·보험이 고객.
  • 03 발사 (언젠가) — 메탄 엔진 기반 자체 발사 능력. 조건이 갖춰졌을 때만 여는 문.

이 저장소의 구조

  • index.html — 사이트 본체 (건드릴 일 없음)
  • posts.js — 개발 로그 데이터베이스. 글은 전부 이 파일에 쌓이고, git 커밋 히스토리가 곧 변경 이력이다.
